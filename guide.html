Playground guide

← back to the playground

The flowmaid playground renders Mermaid-style diagrams with the flowmaid engine (pure Rust, as WebAssembly) and lets you edit flowcharts right on the canvas. Every canvas action is written back into the Mermaid code, so the code panel is always the diagram's source. The diagram syntax itself is covered in the flowmaid documentation.

Editing on the canvas

Visual editing works on flowchart / graph diagrams with the flowmaid engine. The Edit button (V) switches the canvas gestures below on and off; it is on by default.

Nodes

  • Hover a node (tap it on a touch screen) for its toolbar: + adds the next node along the flow, connected, in the nearest free spot (drag + onto another node to connect the two instead); ✎ edits the label; ◩ changes the shape; 🎨 sets a colour; ⧉ duplicates it; 🗑 deletes the node with its edges.
  • Double-click a node to edit its label in place, or empty canvas to add a node there.
  • Drag a node to move it. The layout is saved in the code as a comment line, %% flowmaid:pos A=120,40 B=120,160 … (other Mermaid tools ignore it), so it survives reloads, saved files, share links and AI agents. Auto layout removes it.
  • Shapes: rectangle, rounded, stadium, subroutine, database, circle, double circle, decision, hexagon and both input/output parallelograms.

Edges

  • Drag the ● handle of a selected node, or Shift-drag a node, onto another node to connect them; drop it on empty canvas for a new connected node.
  • Click an edge or its label for its toolbar: edit the label, switch solid / dotted / thick, reverse it, delete it. Double-click an edge to edit its label.

Several nodes and groups

  • Shift-click or Ctrl/⌘-click adds nodes to the selection.
  • The selection toolbar groups them into a subgraph (Ctrl/⌘+G, then type its title), ungroups them, and sets shape, colour, duplicates or deletes for all of them.

Copy, paste & duplicate

  • Ctrl/⌘+C copies the selected nodes as Mermaid text: their definitions, the edges among them, their style lines and their positions. Ctrl/⌘+X cuts.
  • Ctrl/⌘+V pastes them as new nodes in the same arrangement, in the first free spot beside the originals (or in the middle of the view when they are off screen). Ids already in use get new ones, so it works in the same diagram, another diagram or another tab, and Mermaid lines copied from a text editor paste the same way. A line of plain text becomes a node with that label.
  • Ctrl/⌘+D or ⧉ duplicates the selection in one step.

Undo & redo

The ↶ ↷ buttons on the zoom bar and Ctrl/⌘+Z undo one history of the diagram's code, whatever changed it: typing (grouped by pauses), each canvas action, and an AI agent's edits in the live view. It works from the canvas, in fullscreen and with the code panel hidden; moving nodes and Auto layout are steps too, since the layout lives in the code.

View, files & export

  • Pan by dragging empty canvas; zoom with Ctrl/⌘+scroll, pinch, or the zoom bar. Fit frames the whole diagram.
  • ⛶ (Shift+F) shows the canvas alone, fullscreen where the browser allows it.
  • Open a folder or .mmd files (or drop them on the page); Ctrl/⌘+S saves back.
  • Download SVG, or from its menu PNG (2×), copy as image, copy SVG code, or Copy share link.
  • Autosave: the diagram you work on without a file open is kept in this browser and comes back when you reopen the page. Picking an example only replaces it once you edit the example.
  • Share links carry the whole diagram, layout included, compressed in the part of the URL after #, which browsers never send to a server: nothing is uploaded. Opening one leaves your own draft alone until you edit the shared diagram.
  • On a phone the controls sit in one scrolling strip at the top, menus open from the bottom, and edit and zoom share the bottom row.

AI agents (MCP)

flowmaid-mcp is a Model Context Protocol server: Claude Code, Claude Desktop, Cursor and other agents get tools to build, edit and render diagrams with this engine. It also serves this playground on your machine as a live view that stays in sync both ways: the agent's edits appear as you watch, and what you change there is what the agent reads next. The AI button in the playground shows the same setup.

Install

Download the archive for your system from the latest release and put flowmaid-mcp on your PATH, or build it with Rust:

cargo install --locked --git https://github.com/go-routine-id/flowmaid-web flowmaid-mcp

Connect your agent

Claude Code:

claude mcp add flowmaid -- flowmaid-mcp

Claude Desktop, Cursor and others (mcpServers in their config):

{ "mcpServers": { "flowmaid": { "command": "flowmaid-mcp" } } }

Then ask, for example: "Draw our signup flow as a flowchart and open it in the live view."

Live view

  • Runs on 127.0.0.1 (port 7878 or the next free one; FLOWMAID_PORT sets it). The URL carries a session token, so other web pages can't read or change your diagrams.
  • The badge in the corner shows the connection and switches between the agent's documents.
  • An edit you make on top of an older copy (the agent changed it meanwhile) is refused rather than undoing the agent's edit, and the page says so.
